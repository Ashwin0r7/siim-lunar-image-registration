How it works

  1. Add two imagesof the same, or overlapping, lunar ground.
  2. Check the previewsThe tool shows what it can check automatically.
  3. Choose a methodfor finding matching points in both images.
  4. RegisterThe tool aligns the source onto the reference.
  5. Read the resultThe verdict, what it means, and the evidence.
  6. Add a third imageto run loop-closure verification, if you need it.
  7. Inspect the detailsMeasurements, inputs and provenance.

Data provenance

Methodology

Each experiment is pre-registered before it runs; its criteria are reported exactly as frozen, including the ones not met. The verdict rule is unchanged since it was fixed.
